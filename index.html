01 / TRAINING DATASET

나를 학습시킨 데이터

자기소개 내용을 평범한 항목으로 나열하지 않고, AI 모델이 학습하는 데이터셋처럼 구성했습니다. 경험은 입력값이고, 문제 해결은 학습 과정이며, 목표는 모델의 출력값입니다.

DATA 01

Web

HTML, CSS, JavaScript를 통해 사용자가 직접 보는 화면과 웹 서비스의 기본 구조를 익혔습니다.

DATA 02

Server

웹페이지가 단독으로 끝나는 것이 아니라 서버와 데이터를 주고받으며 서비스가 된다는 점에 관심을 가졌습니다.

DATA 03

Network

데이터가 어떤 경로로 이동하고 안정적으로 연결되는지 이해하기 위해 네트워크 분야를 더 깊게 공부하고 싶습니다.

DATA 04

Debug

오류를 만나면 원인을 작은 단위로 나누어 확인하고, 실패를 다음 시도의 로그로 활용하려고 합니다.

DATA 05

AI

장기적으로는 인공지능 모델을 이해하고, 실제 서비스로 연결하는 AI 개발자로 성장하고 싶습니다.

DATA 06

Output

네트워크와 시스템 기반을 이해하는 AI 서비스 개발자가 되는 것이 최종 목표입니다.

AI 서비스는 모델만으로 완성되지 않는다.

저는 장기적으로 인공지능 분야에서 일하는 것을 목표로 하고 있습니다. 하지만 AI 서비스가 실제 사용자에게 제공되기 위해서는 AI 모델 자체뿐만 아니라 서버, 네트워크, 클라우드, 보안과 같은 기반 기술이 함께 필요하다고 생각합니다.

그래서 저는 네트워크 연구실에서 네트워크 구조와 프로토콜, 보안, 트래픽 분석 등을 깊이 공부하고, 이후 AI 모델을 실제 서비스로 연결할 수 있는 개발자로 성장하고 싶습니다.

왼쪽 로그를 선택하면 오른쪽 출력창에 자기소개 내용이 표시됩니다. 평범한 항목을 AI 시스템의 로그처럼 읽히도록 구성했습니다.

IDENTIFY_AI_CANDIDATE

안녕하세요. 저는 웹 프로그래밍을 배우며 인공지능 분야로 성장하고 싶은 김건희입니다. 처음에는 HTML, CSS, JavaScript를 활용해 웹페이지의 화면을 구성하는 것에 관심을 가졌지만, 공부를 하면서 웹 서비스는 단순히 화면만으로 완성되는 것이 아니라는 점을 알게 되었습니다.

사용자의 요청이 서버로 전달되고, 데이터가 네트워크를 통해 이동하며, 다시 화면에 결과가 출력되는 전체 과정이 하나의 서비스라는 점이 흥미롭게 느껴졌습니다. 저는 이러한 흐름을 이해하고, 최종적으로 AI 서비스를 만드는 개발자로 성장하고 싶습니다.

03 / CAREER ROUTING MAP

AI로 향하는 경로

네트워크 연구실은 최종 목적지가 아니라, AI 개발자로 가기 위해 시스템 기반을 이해하는 중요한 라우터입니다.

CLIENT NODE

현재의 나

웹 프로그래밍을 배우며 화면 뒤에서 데이터가 움직이는 구조에 관심을 가지는 단계입니다.

WEB/API ROUTER

웹과 서버

사용자 화면, 요청, 응답, API 통신을 이해하며 서비스 구조의 기본기를 쌓습니다.

LAB SERVER

네트워크 연구실

네트워크, 보안, 클라우드, 트래픽 분석을 공부하며 시스템 기반 역량을 확장합니다.

AI ENGINE

AI 시스템

Python, 데이터 분석, 머신러닝, LLM API 등을 학습해 AI 기술과 서비스를 연결합니다.

DESTINATION

AI 개발자

모델과 서비스 구조를 함께 이해하고 실제 사용자에게 제공되는 AI 서비스를 만드는 것이 목표입니다.

04 / DEPLOY PLAN

배포 전 학습 계획

앞으로의 계획은 단순히 공부 목록을 늘리는 것이 아니라, AI 서비스를 만들기 위한 기반 역량을 순서대로 쌓는 과정입니다.

STEP ROUTE PLAN
01 웹 프로그래밍 기초 강화 HTML, CSS, JavaScript를 활용해 사용자가 보기 편하고 목적이 분명한 웹페이지를 구현하는 능력을 다집니다.
02 서버와 네트워크 이해 HTTP, API, TCP/IP, DNS, 서버 통신 구조 등을 학습하며 웹 서비스가 실제로 동작하는 흐름을 이해합니다.
03 네트워크 연구실 진학 준비 학석사 연계를 목표로 네트워크 보안, 클라우드, 트래픽 분석 등 연구실 분야와 연결되는 주제를 학습합니다.
04 AI 기술 학습 Python, 머신러닝, 딥러닝, 데이터 분석, LLM API 활용 등을 공부해 AI 모델을 이해하고 활용하는 능력을 키웁니다.
05 AI 서비스 프로젝트 AI 모델을 웹 또는 앱 서비스에 연결하고, 서버와 네트워크 기반 위에서 실제로 동작하는 프로젝트를 구현합니다.
06 AI 분야 진출 네트워크와 시스템 기반을 이해하는 AI 개발자로 성장하는 것을 최종 목표로 합니다.
