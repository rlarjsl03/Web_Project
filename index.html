DATA List

관심의 시작점, 기술적 문제의식, 학습 과정, 진로 목표를 하나의 흐름으로 연결해 핵심 경험을 데이터셋 형태로 정리했습니다.

DATA 01

AI Trend

군 복무 이후 AI가 생활 속 여러 영역에 이미 자리 잡았다는 점을 체감하며 진로 방향을 구체화했습니다. 특히 생성형 AI와 추천 시스템이 서비스 품질을 빠르게 바꾸는 과정을 보며 관심이 더 커졌습니다.

DATA 02

Service

AI 모델이 실제 사용자에게 제공되기 위해서는 안정적인 데이터 처리와 서비스 구조가 함께 필요하다고 생각합니다. 요청 처리, 응답 속도, 장애 대응까지 포함한 전체 서비스 관점에서 개발 역량을 키우고자 합니다.

DATA 03

Network

데이터가 어떤 경로로 이동하고 안정적으로 연결되는지 이해하기 위해 네트워크 분야를 더 깊게 공부하고 싶습니다. TCP/IP, 라우팅, 지연 시간, 병목 구간을 실제 사례와 함께 학습해 서비스 성능 개선으로 연결하고자 합니다.

DATA 04

Issue

AI 서비스 증가로 커지는 데이터 전송량, 지연 시간, 트래픽 문제를 중요한 기술 이슈로 바라보고 있습니다. 단순 속도 개선을 넘어 사용자가 체감하는 안정성과 지속 가능한 운영 관점에서 문제를 보고 있습니다.

DATA 05

Debug

오류를 만나면 원인을 작은 단위로 나누어 확인하고, 실패를 다음 시도의 로그로 활용하려고 합니다. 구현보다 설계를 먼저 정리하고, 입력/출력 흐름을 분해한 뒤 검증하는 습관을 통해 문제 해결 정확도를 높이고 있습니다.

DATA 06

Output

네트워크와 시스템 기반을 이해하고 AI를 실제 서비스로 연결하는 개발자가 되는 것이 최종 목표입니다. 사용자에게 신뢰할 수 있는 품질을 제공하는 AI 서비스를 직접 설계하고 운영할 수 있는 개발자로 성장하고자 합니다.

PKT 05 / DEPLOY_AI

최종 목표

AI 모델을 단순히 사용하는 것이 아니라 네트워크 기반 위에서 더 빠르고 안정적으로 제공되는 서비스를 개발하는 것이 목표입니다. 궁극적으로는 사용자 경험과 시스템 안정성을 함께 고려하는 AI 서비스 개발자로 성장하고 싶습니다.

AI 서비스는 모델만으로 완성되지 않는다.

급격한 속도로 변화해가는 기술들을 보았을 때, AI가 이미 검색, 추천, 자동화, 번역처럼 삶의 많은 부분에 자연스럽게 들어와 있다는 점이 가장 크게 다가왔습니다. 그때부터 AI는 먼 미래의 기술이 아니라 직접 배우고 활용해야 할 현실적인 기술이라고 느꼈습니다.

그래서 저는 네트워크 연구실에서 네트워크 구조, 프로토콜, 트래픽 분석, 안정적인 데이터 전송을 공부하고, AI 모델을 실제 사용자에게 더 빠르고 안정적으로 제공하는 서비스 개발자로 성장하고 싶습니다.

또한 관심 기술 학습을 프로젝트로 연결하고, 공모전·인턴십·연구 활동을 통해 진로와 연결된 실전 경험을 쌓아가며 AI 서비스 개발 역량을 강화할 계획입니다. 학습 내용이 이론에 머물지 않도록 결과물을 남기고, 피드백을 반영해 개선하는 과정을 반복하려고 합니다.

STEP ROUTE PLAN
01 AI 기술 흐름 이해 생성형 AI, 머신러닝, LLM 활용 사례를 학습하며 AI가 실제 서비스에 적용되는 방식을 이해합니다.

04 AI 기술 학습 Python, 머신러닝, 딥러닝, 데이터 분석, LLM API 활용 등을 공부해 AI 모델을 이해하고 활용하는 능력을 키웁니다.
05 AI 서비스 프로젝트 AI 모델을 네트워크 기반 서비스 문제와 연결하고, 실제 사용자에게 안정적으로 제공되는 프로젝트를 구현합니다.
06 AI 분야 진출 네트워크와 시스템 기반을 이해하고 AI로 더 나은 서비스를 만드는 개발자로 성장하는 것을 최종 목표로 합니다.
