01 / TRAINING DATASET

나를 학습시킨 데이터

자기소개 내용을 평범한 항목으로 나열하지 않고, AI 모델이 학습하는 데이터셋처럼 구성했습니다. 경험은 입력값이고, 문제 해결은 학습 과정이며, 목표는 모델의 출력값입니다.

DATA 01

AI Trend

군 복무 이후 AI가 이미 생활 속 여러 영역에 들어와 있다는 점을 체감하며 진로 방향을 구체화했습니다.

DATA 02

Service

AI 모델이 실제 사용자에게 제공되기 위해서는 안정적인 데이터 처리와 서비스 구조가 함께 필요하다고 생각합니다.

DATA 03

Network

데이터가 어떤 경로로 이동하고 안정적으로 연결되는지 이해하기 위해 네트워크 분야를 더 깊게 공부하고 싶습니다.

DATA 04

Issue

AI 서비스 증가로 커지는 데이터 전송량, 지연 시간, 트래픽 문제를 중요한 기술 이슈로 바라보고 있습니다.

DATA 05

Debug

오류를 만나면 원인을 작은 단위로 나누어 확인하고, 실패를 다음 시도의 로그로 활용하려고 합니다.

DATA 06

Output

네트워크와 시스템 기반을 이해하고 AI를 실제 서비스로 연결하는 개발자가 되는 것이 최종 목표입니다.

02 / PRETEXT NETWORK

패킷을 해독하는 자기소개

노드를 선택하면 네트워크 패킷이 이동하고, 문장이 암호화된 문자에서 실제 자기소개 내용으로 복원됩니다. 문단을 그냥 보여주는 대신 텍스트가 처리되는 과정을 시각적으로 드러냈습니다.

군 복무 이후 AI가 이미 삶의 많은 부분에 들어와 있다는 점을 체감했고, 이 변화가 AI 서비스 개발에 관심을 갖게 된 계기가 되었습니다.

model_training.log

> loading student_profile.json

AI 서비스는 모델만으로 완성되지 않는다.

군 복무 이후 다시 사회의 기술 변화를 바라보았을 때, AI가 이미 검색, 추천, 자동화, 번역처럼 삶의 많은 부분에 자연스럽게 들어와 있다는 점이 가장 크게 다가왔습니다. 그때부터 AI는 먼 미래의 기술이 아니라 직접 배우고 활용해야 할 현실적인 기술이라고 느꼈습니다.

그래서 저는 네트워크 연구실에서 네트워크 구조, 프로토콜, 트래픽 분석, 안정적인 데이터 전송을 공부하고, AI 모델을 실제 사용자에게 더 빠르고 안정적으로 제공하는 서비스 개발자로 성장하고 싶습니다.

안녕하세요. 저는 AI와 네트워크 기술을 중심으로 성장하고 싶은 개발자 김건희입니다. 최근 발전하는 AI가 사회의 큰 부분을 차지하고 일상생활을 편리하게 만드는 모습에 매력을 느껴, 네트워크 기반 위에서 더 나은 AI 서비스를 만드는 방향으로 공부를 이어가고 있습니다.

제가 이루고 싶은 목표는 AI를 활용해 학석사 연구실인 네트워크 연구실에서 더 나은 서비스를 개발하는 것입니다. 모델 성능뿐 아니라 데이터가 안정적으로 이동하고 사용자에게 빠르게 전달되는 과정까지 이해하는 개발자가 되고 싶습니다.

04 / CAREER ROUTING MAP

AI로 향하는 경로

네트워크 연구실은 최종 목적지가 아니라, AI 개발자로 가기 위해 시스템 기반을 이해하는 중요한 라우터입니다.

CLIENT NODE

현재의 나

AI가 생활 속에서 활용되는 흐름을 보며 네트워크 기반 서비스 개발에 관심을 가지는 단계입니다.

SERVICE ROUTER

서비스 구조

AI 모델이 실제 서비스로 제공되기 위해 필요한 데이터 흐름과 시스템 구조를 이해합니다.

LAB SERVER

네트워크 연구실

네트워크, 클라우드, 트래픽 분석, 데이터 전송 한계 해결 방안을 공부하며 시스템 기반 역량을 확장합니다.

AI ENGINE

AI 시스템

Python, 데이터 분석, 머신러닝, LLM 활용 등을 학습해 AI 기술을 실제 서비스 문제와 연결합니다.

DESTINATION

AI 개발자

네트워크 기반을 이해하고 실제 사용자에게 더 빠르고 안정적으로 제공되는 AI 서비스를 만드는 것이 목표입니다.

05 / DEPLOY PLAN

배포 전 학습 계획

앞으로의 계획은 단순히 공부 목록을 늘리는 것이 아니라, AI 서비스를 만들기 위한 기반 역량을 순서대로 쌓는 과정입니다.

STEP ROUTE PLAN
01 AI 기술 흐름 이해 생성형 AI, 머신러닝, LLM 활용 사례를 학습하며 AI가 실제 서비스에 적용되는 방식을 이해합니다.
02 네트워크 기반 이해 TCP/IP, 라우팅, 지연 시간, 대역폭 등 데이터가 안정적으로 전달되는 구조를 학습합니다.
03 네트워크 연구실 진학 준비 학석사 연계를 목표로 네트워크 구조, 데이터 전송, 트래픽 분석 등 연구실 분야와 연결되는 주제를 학습합니다.
04 AI 기술 학습 Python, 머신러닝, 딥러닝, 데이터 분석, LLM API 활용 등을 공부해 AI 모델을 이해하고 활용하는 능력을 키웁니다.
05 AI 서비스 프로젝트 AI 모델을 네트워크 기반 서비스 문제와 연결하고, 실제 사용자에게 안정적으로 제공되는 프로젝트를 구현합니다.
06 AI 분야 진출 네트워크와 시스템 기반을 이해하고 AI로 더 나은 서비스를 만드는 개발자로 성장하는 것을 최종 목표로 합니다.
